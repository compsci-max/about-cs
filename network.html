How Internet Packet Routing Works

1 DNS Lookup (UDP)

Before a client connects to a server domain (like example.com), it sends a fast, lightweight UDP query on Port 53 to resolve the human-friendly URL into a numerical IPv4/IPv6 address.

2 TCP 3-Way Handshake

For reliable protocols like HTTP, a connection must be established before sending data. This is done via SYN (Synchronize), SYN-ACK (Acknowledge), and ACK packets to sync sequence numbers.

3 Router Hops & TTL

Packets travel across intermediate switches and routers. Each router decrements the packet's Time-To-Live (TTL) field by 1. If TTL hits 0, the packet is discarded to prevent infinite looping.
